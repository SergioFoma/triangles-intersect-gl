# Тесты

Тесты `Point3D` охватывают:

- инициализацию координатами;
- невалидность точки, созданной без координат;
- проверку конечных и невалидных координат через `IsValid()`;
- вывод координат через `Print()`.

Тесты `Triangle3D` проверяют сохранение трёх вершин и валидность обычного
треугольника и треугольника с невалидной вершиной. Проверки валидности пока
должны падать: `Triangle3D::IsValid()` оставлен заглушкой для следующего шага.

Для запуска:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```
