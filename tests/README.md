# Тесты

Тесты `Point3D` охватывают:

- инициализацию координатами;
- невалидность точки, созданной без координат;
- проверку конечных и невалидных координат через `IsValid()`;
- вывод координат через `Print()`.

Тесты `Triangle3D` проверяют сохранение трёх вершин, валидность обычного
треугольника и отклонение вершин с невалидными координатами. Тесты `Intersects`
охватывают треугольники в разных плоскостях и в одной плоскости: наложение,
вложение, касание по ребру или вершине, раздельные фигуры и близкий промах.
Копланарные случаи включают плоскости `z = 0`, `z = 5` и `x = 1`, а также
обратный порядок вершин. Касание считается пересечением; каждый сценарий
проверяет оба порядка аргументов. Отдельные проверки `IsCoplanar` различают
совпадающие, параллельные и пересекающиеся плоскости.

Для запуска:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Все сценарии запускаются одним исполняемым файлом `triangles_tests` и одной
записью CTest.
